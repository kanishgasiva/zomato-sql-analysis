# Zomato Restaurant Analysis

Project Overview
--
Analysis of Zomato restaurant data using SQL to identify trends across various restaurant attributes and derive meaningful business insights

Objective
--
To understand restaurant distribution, ratings, customer engagement, and other business patterns using SQL.

Dataset 
--
Source: Kaggle

Link: [ kaggle.com/datasets/shrutimehta/zomato-restaurants-data ](https://kaggle.com/datasets/shrutimehta/zomato-restaurants-data)

Contains restaurant-level information including location, ratings, votes, cuisines, cost, and other restaurant attributes.

Project Workflow
--
- Download and explore the dataset using SQL
- Clean and prepare the data for analysis
- Perform exploratory data analysis
- Answer business questions using SQL queries
- Identify key insights from the analysis

Exploratory Analysis
-- 
1. How many restaurants are there in each city and country?
2. What are the most common cuisines?
3. What currencies are used?
4. What is the overall voting distribution?
5. What is the cost range for two people?
6. How are restaurants distributed across localities in Indian cities?

Business Questions
--
1. Which Indian cities have the most restaurants?
2. What are the most popular cuisines in India?
3. How widely is online delivery adopted across cities?
4. Does table booking relate to ratings and votes?
5. Which restaurants offer high ratings at relatively low cost?
6. Which cities have the most Excellent-rated restaurants?

Key Insights
--
The analysis transformed raw restaurant data into a structured dataset and used SQL to identify patterns in restaurant distribution, ratings, pricing, cuisines, and customer engagement

Files
--
* `zomato_analysis.sql` — Data cleaning and exploratory analysis queries
* `zomato.csv` — Dataset
